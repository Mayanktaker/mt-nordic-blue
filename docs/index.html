MT Nordic Blue

A modular dark theme suite for Linux featuring frosted glassmorphism, 4 top bar styles, rounded & sharp corner modes, matching vector icons, custom cursors, and procedural 4K wallpapers.

Built-In Modular Options

Tune your desktop experience using the interactive CLI wizard or direct command flags.

🧊

Frosted Glass & Blur

28px backdrop blur and translucent surfaces on panels, popovers, and quick settings. Fully compatible with native GNOME Shell and the Blur my Shell extension.

📐

Rounded & Sharp Corners

Choose between modern 16px smooth curved window corners, dialogs, and button rounding OR 0px sharp non-rounded corners for tiling window managers and minimalist setups.

⚡

Standard & Compact Sizes

Toggle between comfortable upstream GNOME proportions and compact density featuring 34px slim headerbars, 24px buttons, and tight list spacing.

🛸

4 Top Bar Island Styles

Select from floating 16px curved island, 999px capsule pill, bottom-rounded attached bar, or classic full-width edge-to-edge flat bar.

🎨

3 Base Palettes in One

Includes Deep Polar Night (#0E141D, default), Classic Nord Spec (#2E3440 slate), Arctic Cyber Frost (#0A0E17 midnight navy), plus true OLED black.

✨

6 Nordic Accent Flavors

Switch between Nordic Frost (#88C0D0), Glacier Ice (#81A1C1), Aurora Teal (#8FBCBB), Deep Arctic (#5E81AC), Cyber Neon (#00D2FF), and Blaze Amber (#D08770).

Installation & Quick Start

Installed strictly at user level into ~/.themes and ~/.icons without root privileges.

bash — installation wizard
# 1. Clone repository
$ git clone https://github.com/Mayanktaker/mt-nordic-blue.git && cd mt-nordic-blue
# 2. Launch interactive setup wizard (guides through all options)
$ ./install.sh
# Or install headlessly with preferred configuration flags:
$ ./install.sh --panel round-island --corners round --blur --icons --wallpaper 1
# For sharp corners and compact developer aesthetic:
$ ./install.sh --panel flat --corners sharp --size compact --no-blur --icons
