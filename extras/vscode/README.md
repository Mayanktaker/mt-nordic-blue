# MT Nordic Blue — VS Code Theme

© Mayanktaker Computers & Web Development | https://mayanktaker.com

Companion VS Code dark theme with syntax colors tailored to the MT Nordic Blue palette.

## Installation
Copy this folder into your VS Code / Cursor extensions directory:
```sh
mkdir -p ~/.vscode/extensions/mt-nordic-blue-theme
cp -r package.json themes/ ~/.vscode/extensions/mt-nordic-blue-theme/
```
Then restart VS Code and select **MT Nordic Blue** from `Preferences: Color Theme` (`Ctrl+K Ctrl+T`).
